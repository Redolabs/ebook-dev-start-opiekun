# Rozwiązania zadań: Mini-framework PHP krok po kroku

Plik dla opiekuna. Każde zadanie ma kod w stanie zgodnym z rozdziałem, w którym zadanie występuje, oraz krótką listę rzeczy, na które warto spojrzeć przy review commita. Kod jest punktem odniesienia, nie jedyną poprawną wersją: jeśli rozwiązanie ucznia działa, jest bezpieczne i czytelne, zostaw je. Zasada z przewodnika obowiązuje także tutaj: gdy uczeń utknie, podpowiadasz kierunek (nazwę funkcji, krok z rozdziału), nie pokazujesz tego pliku.
